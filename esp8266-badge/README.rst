==================
Hedonism Bot badge
==================

This was my first attempt to create an electronic badge. The Hedonism Bot is a character from Futurama_.

I made a mistake with that OLED display, the pinout on the pcb isn't compatible with the most common SSD1306 OLED display.

.. _Futurama: https://theinfosphere.org/images/cache/4/44/Hedonism_Bot.html
